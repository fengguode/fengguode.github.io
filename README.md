# Feng Guo — public CV website

Static, responsive CV website for GitHub Pages. It includes only the public CV profile, portrait and general CV PDF.

## Publish

1. Create the public repository `fengguode/fengguode.github.io`.
2. Copy the files in this directory into the repository root.
3. Under Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. GitHub Pages will publish at `https://fengguode.github.io/`.

The private `About_Me` repository remains the source for application materials. Do not copy credentials, applications or internal documents into the public repository.

## Update

Edit `index.html` for the CV text and `style.css` for the design. Replace `assets/Feng_Guo_CV.pdf` when the general CV changes. All asset URLs are relative; there are no analytics, external fonts or dependencies.
